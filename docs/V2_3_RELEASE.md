# v2.3 五份和平合約

本輪包含五章 Boss、隨機分岔冒險、NPC 小隊與場景變化；沿用原有固定操作列、造型、稱號、裝備防誤換、音樂與 v2 存檔。

## 首領與難度

| 章節 | 首領 | 建議等級 | 主要強項與應對 |
| --- | --- | ---: | --- |
| 1 | 不死巫妖 | 7 | 魔防高；靈魂催繳用砍擊打斷 |
| 2 | 火焰巨龍 | 12 | 攻擊力強；吸氣時魔法冷卻，噴火時堅守 |
| 3 | 遠古魔神 | 19 | 累積毒；魔法打斷毒霧，解毒清除層數 |
| 4 | 發條典獄長 | 26 | 裝甲鎖、讀取連續同招；魔法拆甲，堅守大印章 |
| 5 | 骰骨大公 | 34 | 輪替抗性；兩回合蓄力期間以兩種不同招式破印 |

等級是一般配裝的挑戰目標，不是硬門檻，也不保證必勝。首領數值按章節固定，不會隨玩家升級同步變強。最大普通等級提升至 40，滿級後保留巔峰成長。每個首領有獨立配樂。

校準方法：每王分別在建議等級前 3 級、建議等級、後 3 級，用自然成長加固定中階裝備、生命戒指、3 藥水與 3 解毒藥進行各 20 種戰鬥亂數比較。模型沒有狐狸或奇物；一種策略使用已揭露預告、補給與破招，另一種只連點砍擊。這是平衡用的裝備固定案例，不能當作真實玩家勝率。

校準時，在建議等級使用預告應對的成功次數依序為 15/20、11/20、13/20、12/20、13/20；只連點砍擊依序為 4/20、0/20、0/20、0/20、0/20。完整數據見 test-reports/v23-balance-report.json。

## 路線與故事

每次探索先呈現三條不同類型路線：普通戰鬥、菁英、事件、寶物、休息、奇物。已產生的路線與旅程亂數狀態會保存，重整不會重抽。先取得各章 4／5／6／7／8 條探索線索，才可挑戰首領。

五種天氣與十件奇物改變當次旅程，最多攜帶五件奇物。取得順序、商店消費、臨時同行夥伴與事件選項形成不同組合。新增雞借創業基金的後續、會罷工的行李、要面試的門、史萊姆法庭、幽靈樂團等荒唐事件，並保留原有狐狸與郵差故事。

## 有交情的 NPC，不是真人連線

十位有姓名、稱號、職業與性格的 NPC，保存等級、HP、交情、相遇次數及勝場。人物在再次相遇時逐步恢復或成長，不是伺服器上的真人玩家，也不是背景中永遠開著的其他遊戲程序。

村莊顯示兩位可直接點選交談的居民；每次探索回來，人物組合可能改變。同一段探索不反覆發放免費對話獎勵。事件可同時出現兩、三人，交情會影響台詞；部分人物可暫時陪打兩場、每四回合提供一次支援。

新增小隊問路、劍士切磋、盜賊三人組、市集扒手、護衛背叛商人、酒館組隊、沼澤救援與假守衛。對敵人可交手、交涉、逃離；機率與損失先寫在選项上。NPC 隊伍共用一條合計生命條，戰勝可拿經驗、裝備與額外金幣，不會重複結算。扒手最多扣當前金幣 15%／18 金幣，絕不偷走玩家裝備。

逃跑看等級差、閃避與狐狸加成；交涉看等級差、平手勝率與名聲。成功率限制在 15%～90%。普通戰鬥可消耗一回合逃跑，失敗受到追擊，成功沒有戰利品。首領戰不可逃跑。

## 場景與操作

十二種場景變體：森林、村莊、市集、酒館、洞穴、沼澤、商道、營地、祠堂、龍巢、城寨與骰宮。使用原像素地景加簡單建築／地形圖層，跟隨事件或首領切換；沒有每幀重畫循環，也沒有外部圖片串流。

固定操作列新增堅守、藥水、解毒與逃跑。藥水與解毒都消耗回合；敵人仍會行動。毒傷、首領蓄力和臨時隊友狀態會存檔。

## 相容性與驗收範圍

舊角色的等級、裝備與基礎數值不重設。舊三王通關存檔接到第四章，先前的通關名冊保留；第五章完成另記錄五章成績。原自動存檔、備援、手動槽與 JSON 匯出匯入繼續有效。

測試程式：tests/regression.mjs、campaign.mjs、v21.mjs、v22-release.mjs、v23.mjs、npc-world.mjs 等。測試包含事件各選項、首領打斷／蓄力／毒、路線與 NPC 存讀檔、舊檔遷移、裝備防誤換、固定選單、多種視窗尺寸與完整五章流程。平衡測試另由 tests/v23-balance.mjs 產生。

瀏覽器模擬手機尺寸不等於已在每款實體手機驗證；Safari 與極端裝備組合仍有不確定性。正式部署以 GitHub Actions 測試與實站檢查結果為準。
