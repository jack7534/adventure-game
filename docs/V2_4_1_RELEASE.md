# v2.4.1 戰鬥節奏與中後期遇敵調整

這次只調整路線、連續獵怪與普通／菁英敵人的數值。五王設計、32 種造型、八種寵物、具名 NPC、裝備詞條與原存檔 key 保留。

## 戰鬥更容易直接遇到

新產生的三岔路固定為兩條戰鬥路、一條事件／補給路。第一條永遠是普通戰鬥；Lv.1～3 第二條也是普通戰鬥，Lv.4 起第二條有 35% 機率改為菁英。兩條普通路有不同地形與怪物池。菁英卡片標明高風險與直接開戰，不再先進入切磋對話。

第三條保留劇情、寶物、休息或奇物。這是「可選路線有 2/3 是戰鬥」，不是宣稱每位玩家實際戰鬥率為 67%；玩家仍可選擇和平路線。已出現的舊版路線不重抽。

普通／菁英／敵對 NPC 勝利、處理完戰利品後，可按「繼續獵怪」直接接下一場普通戰鬥，也可換路或回營地。每次接戰照常計算一次探索與線索，不送額外勝利獎勵、不免費回血或補充藥水。尚未選擇裝備時不能跳過；首領勝利、戰敗、逃跑不顯示連續獵怪。

## 中後期依入場配裝部分適應

第二章起，或第一章達 Lv.8 後，普通怪與菁英會使用玩家的常態配裝快照調整：攻擊、魔攻、防禦、最大 HP、平均爆擊／多段傷害，以及出戰寵物的部分輸出／回復。未出戰寵物不計算。前期第一章 Lv.1～7 不套用這項適應。

敵人 HP 對輸出採小於一次方的曲線，而不是玩家傷害翻倍、怪物 HP 就照著翻倍。物防／魔防保留怪物本身比例；石頭人、骷髏、狼與蝙蝠的弱點、迴避和出招偏好仍不同。防禦、護盾、治療與強裝仍有價值，不複製玩家的閃避與平手勝率。

計算以滿血、無臨時破甲的常態數值為準，不因玩家目前殘血或短期加持重抽難度。開戰後的 HP、攻防等數值直接保存；重整、讀檔和同場更新畫面不會再次縮放。已在進行的舊戰鬥維持原數值。畫面新增敵人物攻與「入場配裝適應 Lv.」標記。

五隻 Boss 仍用原本固定的章節數值；具名 NPC 小隊不納入這次小怪適應。怪物較強不代表取消原有的戰利品或升級獎勵。

## 驗證方式

`tests/combat-pace.mjs`：三岔路分布、舊路線存讀檔、直接開戰、戰利品阻擋、連點防護、HP／毒／補給接續、回營地，以及手機固定按鈕可點性。

`tests/encounter-balance.mjs`：早期保護、攻擊／魔攻／防禦／HP／寵物參考、怪物種族差異、不消耗亂數、不修改玩家、戰鬥快照、舊檔相容，以及 Boss 不被縮放。數值範例採合成測試配裝，不能視為玩家真實存檔或玩家勝率。

完整回歸另執行五組自然成長的五章通關、NPC、寵物、音樂、裝備與存讀檔。行動裝置以瀏覽器尺寸模擬，不代表已驗證全部實體手機。
